# Как получить ключ OpenAI (быстрый провайдер, ~20 сек вместо нескольких минут)

Бесплатный NVIDIA NIM ([07-NVIDIA-NIM-GUIDE.md](07-NVIDIA-NIM-GUIDE.md)) работает, но на
нескольких фото параграфа может занимать несколько минут — свободный тариф читает
фото по одному. OpenAI (`gpt-4o-mini`) читает все фото одним запросом за ~10-20 секунд
и гарантированно возвращает корректный ответ. Стоимость на весь класс на семестр —
несколько центов из бюджета в $9.

Если ключ не задан — приложение просто продолжит работать через NIM, ничего не сломается.

## 1. Регистрация и оплата

1. Открой **platform.openai.com** → зарегистрируйся (можно через Google-аккаунт).
2. Слева **Settings → Billing** → **Add payment method** — привяжи карту.
3. Там же можно поставить **Usage limit** (например, $5) — не даст случайно потратить
   больше бюджета, даже если что-то пойдёт не так.

## 2. Выпустить API-ключ

1. Слева **API keys** → **Create new secret key**.
2. Ключ показывается **один раз** — сразу скопируй, начинается с `sk-...`.
3. Если потерял — сгенерируй новый, старый можно отозвать там же.

## 3. Куда вставить ключ

В файле `.env.local` в корне проекта:

```
OPENAI_API_KEY=sk-твой-ключ-сюда
```

На Vercel — то же самое через **Settings → Environment Variables** после деплоя.

## 4. Проверить, что работает

Перезапусти `npm run dev` (переменные окружения читаются при старте) и сфотографируй
параграф через `/capture`. Смотри на поле `"source"` в результате:

- `"source": "openai"` — сработал быстрый платный путь, ~10-20 секунд.
- `"source": "nim"` — OpenAI не подключён или недоступен, отработал бесплатный резерв
  (медленнее, но тоже честно).
- `"source": "offline-example"` — оба провайдера недоступны, показан заранее
  подготовленный пример.

## Сколько потратится

`gpt-4o-mini` стоит $0.15 за 1 млн входных токенов и $0.60 за 1 млн выходных.
Один разбор параграфа (даже с 5 фото) — это доли цента. $9 бюджета хватит на тысячи
разборов, то есть на весь класс на весь учебный год с огромным запасом.
