# Эхо — комплект документации для сборки

Этот комплект — всё, что нужно, чтобы отдать проект «Эхо» в Claude Code и получить
рабочий сайт на Vercel, без покупки домена и хостинга, в бюджет **$10**.

## Что внутри

| Файл | Что там | Когда читать |
|---|---|---|
| `01-PRD.md` | Полный маршрут пользователя, список фич по приоритету, почему это должно выиграть конкурс | Прочитать первым — это бриф продукта |
| `02-ARCHITECTURE.md` | Стек, все API, бюджет по $10, схема отказоустойчивости | Перед тем как начать кодить |
| `03-DESIGN-SYSTEM.md` | Дизайн в стиле Airbnb, адаптированный под образование: палитра, шрифты, компоненты, иллюстрации | Перед вёрсткой любого экрана |
| `04-PROJECT-STRUCTURE.md` | Точная структура папок и файлов репозитория | Перед тем как Claude Code создаст первый файл |
| `05-CLAUDE-CODE-PROMPT.md` | Готовый промпт — вставить в Claude Code первым сообщением | В самом конце, когда всё остальное на месте |

## Порядок действий

1. Создать пустой репозиторий на GitHub (например `echo-trainer`).
2. Положить в него папку `docs/` целиком (все файлы из этого комплекта).
3. Открыть репозиторий в Claude Code.
4. Скопировать содержимое `05-CLAUDE-CODE-PROMPT.md` целиком и отправить как первое сообщение.
5. Когда Claude Code соберёт первую рабочую версию — подключить репозиторий к Vercel (Import Project → выбрать репозиторий → Deploy). Vercel сам даст бесплатный адрес вида `echo-trainer.vercel.app`.
6. Завести бесплатные ключи (раздел «Ключи, которые нужно получить руками» в `02-ARCHITECTURE.md`) и вписать их в Vercel → Settings → Environment Variables.

## Один принцип на весь проект

Не как у всех — не потому что сложнее, а потому что надёжнее. Половина школьных проектов
проигрывает не из-за слабой идеи, а потому что демо на защите не сработало — не было
интернета, кончился лимит нейросети, микрофон не поймал звук. Каждое решение в этих
документах в первую очередь отвечает на вопрос «а что если это сломается прямо на сцене» —
и только потом на вопрос «как это сделать круто».
