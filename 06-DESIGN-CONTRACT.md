## Запретный список (антислоп) — таблица «нельзя / почему»

| Нельзя | Почему |
|---|---|
| Градиент под карточкой/кнопкой как заглушка пустоты | Маркер слопа №1 — дешёвый способ закрыть пустой фон |
| Мелкий текст капсом с разрядкой («LIVE», «SYNC» и т.п.) | Второй маркер слопа, модель считает это «технологичным», выглядит наоборот |
| Точка-разделитель в мете (`3 параграфа • стрик 5 • история`) | Опознаётся за секунду, признак не вычитанного текста |
| Дефолтная тема shadcn (радиусы/цвета/шрифт из коробки) | Так выглядит половина проектов на рынке — обязательна кастомизация радиусов, цвета, типографики |
| Стекло/blur без контента под ним | Дорогой способ нарисовать серый прямоугольник |
| Текст без работы (слоганы, манифесты под карточками) | Проверка: убрал текст — ничего не сломалось, значит лишний |
| Больше одного акцентного цвета на экран | `--accent` только на главном действии; `--good`/`--warn` — это состояние, не украшение |
| Inter / Roboto / Arial / Helvetica | Уже решено проектом — Nunito + PT Sans, кириллица в обеих проверена |
| Эмодзи вместо иконок | Только SVG-иконки (один набор на проект), эмодзи — нигде в интерфейсе |

## Контракт для Главного экрана конкретно

- **Один экран — одно действие.** Карточка «📷 Сфотографировать параграф» ничего не делит с другими элементами по визуальному весу.
- **Иерархия сверху вниз:** заголовок-приветствие (тёплый, по имени интереса из онбординга) → крупная CTA-карточка → компактная строка статуса (параграфов пройдено · стрик) без точки-разделителя, разделяю смысловым интервалом или лёгкой вертикальной чертой `--line` → нижняя навигация из 3 пунктов.
- **Строка статуса — не декор.** Каждое число кликабельно ведёт в «Историю»; если данных ещё нет (первый заход) — состояние конкретное («Пока 0 параграфов — начни с первого»), не заглушка.
- **Форма:** карточка — радиус 20px, кнопки/пилюли статуса — 14px/100px как в 03-DESIGN-SYSTEM.md. Тень мягкая многослойная, ни одной резкой чёрной.
- **Иллюстрация не нужна на этом экране** (она про ожидание/пустые состояния) — здесь работает сама крупная кнопка-карточка, лишний визуальный шум только отвлечёт от единственного действия.
- **Motion:** лёгкий подъём карточки при нажатии (150-200ms), уважение `prefers-reduced-motion`. Никакой бесконечной анимации на статике.

## Self-check перед показом пользователю

- [ ] Ни одного запрещённого паттерна из таблицы выше
- [ ] Шрифты — Nunito (заголовок) + PT Sans (текст), кириллица проверена
- [ ] Каждый текстовый элемент выполняет работу — ничего для «красоты»
- [ ] Мобильная раскладка от 375px, нижняя навигация из 3 пунктов
