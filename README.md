# Эхо — тренажёр пересказа

Школьный проект: фотографируешь параграф учебника → нейросеть объясняет его простыми
словами и аналогиями под твой интерес → пересказываешь вслух своими словами →
получаешь честный ответ, что запомнил, а что нет.

Идея в основе: зубрёжка не работает, а пересказ своими словами — работает (эффект
Фейнмана). Приложение превращает это в 5-минутный цикл, который можно повторять
на каждом уроке.

## Как это работает

1. **Сфотографировать параграф** — камера телефона или файл из галереи.
2. **Простое объяснение** — NVIDIA NIM (мультимодальная модель) читает фото и
   объясняет текст простыми словами, с аналогиями под интерес ученика (футбол,
   игры, музыка и т.д.), подсвечивает ключевые термины.
3. **Пересказ вслух** — запись через Web Speech API прямо в браузере, бесплатно и
   без сервера.
4. **Честная проверка** — тот же ИИ сравнивает пересказ с ключевыми пунктами
   параграфа и показывает, что было названо, а что нет — без завышенных оценок.
5. **История и стрик** — прогресс сохраняется в Neon Postgres и виден на вкладке
   «История».

Если ИИ-провайдер недоступен (лимит, сеть, ошибка), каждый экран деградирует до
заранее продуманного запасного пути вместо голой ошибки — подробности в
[02-ARCHITECTURE.md](02-ARCHITECTURE.md).

## Стек

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **[Astryx](https://www.npmjs.com/package/@astryxdesign/core)** — дизайн-система компонентов
- **NVIDIA NIM** — бесплатный тариф, vision-модель для объяснения фото и проверки пересказа
- **Web Speech API** — озвучка и распознавание речи прямо в браузере, без затрат
- **Neon Postgres** (опционально) — история занятий и статистика пилота
- **Upstash Redis** (опционально) — кэш ответов и защита от превышения лимита ИИ
- PWA-манифест — устанавливается на экран телефона

Без ключей и БД приложение продолжает работать: показывает офлайн-пример вместо
вызова ИИ и честный ноль вместо статистики — ничего не падает.

## Запуск локально

```bash
npm install
cp .env.local.example .env.local   # и вписать свои ключи — см. 07-NVIDIA-NIM-GUIDE.md
npm run dev
```

Откроется на `http://localhost:3000`.
